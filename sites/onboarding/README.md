# onboarding

**Responsibility**: Intake form data and onboarding input — the raw client information captured before a client site is assembled.

**Allowed**: Onboarding form data, intake submissions, and the structures that hold captured client input.

**Prohibited**: Rendering logic and components (→ `core`), and assembled client config (→ `clients`).

**Depends on**: `core` (for shared types/schemas). Does not depend on `templates` or `clients`.
