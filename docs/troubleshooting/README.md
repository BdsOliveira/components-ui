# Troubleshooting

> **Pré-requisitos**: [Índice principal](../README.md).

Quando algo falha, comece aqui: sintoma → causa provável → correção, sem depurar do
zero.

## Documentos

- [Problemas comuns](./problemas-comuns.md) — os 7 sintomas mais frequentes, cada

## Os 7 sintomas cobertos

1. Seção não renderiza
2. Estrutura de config inválida
3. Assets (imagens) faltando
4. Problemas de hidratação
5. Problemas de SSR
6. Problemas de deployment
7. Falha de resolução de template
