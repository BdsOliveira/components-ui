# Componentes

> **Pré-requisitos**: [Arquitetura em camadas](../architecture/arquitetura-em-camadas.md).
> **Tema**: components

Os componentes de seção (`sites/core/components/sections/`) são os blocos
reutilizáveis montados pelos templates. Esta seção define o que torna um componente
"válido" na plataforma.

## Documentos

- [Padrões de componente](./padroes-de-componente.md) — critérios objetivos de
  componente "válido" (FR-011/FR-012).

## Os oito blocos atuais

Fonte: `sites/core/components/sections/register.ts`

`HeroSection`, `AboutSection`, `ServicesSection`, `CtaSection`, `TestimonialsSection`,
`FaqSection`, `ContactSection`, `FooterSection`.
